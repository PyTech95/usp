# USP India — Photo Asset and Approval Guide

Prepared from the 20 uploads supplied with the brief. This is an inventory and proposed handling plan, not a statement that photographs have been retouched, permissions obtained, or a website built.

## Rules that apply to every upload

Retain the supplied source file unchanged. Create any crop, colour correction or web export as a separate derivative. Public use requires confirmation of provenance, appropriate permission and approval of the particular derivative. Permission documents and annotated instructions belong in protected storage, not a public media directory.

The preferred presentation is documentary and natural. Do not replace a photograph with generated people, a reconstructed scene, added craft pieces or beautified faces. Do not infer a person's name, community, role, exact age or location from appearance. Captions below are descriptive proposals, not verified event records.

## CMS metadata to record

Each asset should have a source file, source dimensions, checksum, source type, related versions, proposed page placement, public caption, alt text, photographer/rights credit, permission status, edit approval status, protected permission evidence, focal point, usage locations and edit history.

Keep “source is an original”, “person/property permission is approved”, and “this edit is approved” separate. None of those automatically proves the others.

## Resolution and composition notes

The two explicitly named originals are 1280 × 960. The site can display them attractively at a restrained width, but stretching them or exporting them at 4K does not create real extra detail. Never apply generative face recovery to compensate for the available resolution.

For the group photograph, use the full 4:3 composition where needed. A shallow panoramic hero or an automatic mobile `object-fit: cover` treatment risks removing women, the roof or pillars. The web layout should accommodate the documentary frame rather than force the frame into a template.

The statement about using a “large picture” is not securely attached to a specific upload in the supplied text. Keep that placement pending instead of presenting one interpretation as a confirmed client instruction.
